Your server

The address you open Tandoor at in your browser.

The token stays on your phone. It lets the watch read your recipes and log what you cook.

Where do I get a token?
  1. In Tandoor, open the user menu and choose Settings.
  2. Open API tokens and create a token with the scope read write.
  3. Copy the token and paste it above. Tandoor shows all of it only once.

Write access lets the watch log a cook when you finish a recipe. With a read only token everything else works.
